# AIに聞かれる宿 一斉診断（公開集計）

`summary.json` は、温泉地の旅館サイトをAIに読ませ、12問に答えられるかを一斉に診断した結果の集計値です。

- 「答えられた」は、サイト本文に根拠となる記述があるという意味です。内容が事実どおりかは確かめていません。
- 対象は宿泊料金トレンドで料金を見ている宿のうち、公式サイトを取得できた宿です（`overall.inns`）。
- 5軒未満の区分は出していません（`suppressed_groups` は出さなかった区分の数）。
- 市場（温泉地）ごとの区分は、答えられた数の平均・中央値・割合と記載なしの平均・中央値だけです。
- ページ同士の食い違いは確かめられていないため、件数を出さず「宿に確認を」に含めています。
- 質問ごとの `one_short` は、答えられなかった宿のうち足りないのが1要素だけだった宿の数と、足りない要素ごとの内訳です（全体と規模区分だけ）。
- 宿ごとの結果は公開していません。
- ラボのページ（`/ai-inn-diagnosis/bulk/`）はこのファイルだけから作ります。差し替えたら `python scripts/build_ai_inn_bulk.py` を実行します。
